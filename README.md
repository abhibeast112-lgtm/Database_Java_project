# Subscription Management System

A Java desktop application for managing customers, subscription
plans, subscriptions, renewals, cancellations, and payment records.

## Tech Stack
- Java 17+
- Java Swing
- JDBC
- MySQL
- Maven

## Features
- Customer management
- Subscription plan management
- Subscription tracking
- Renewals and cancellations
- Payment records

## Setup
1. Create the database using sql/schema.sql.
2. Set DB_USER and DB_PASSWORD environment variables.
3. Run mvn compile.
4. Launch the app using Maven.
